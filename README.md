# Painel Terra di Fiori

Painel público com visitas, carrinho, checkout e compras do site terradifiori.com.br, a partir do Pixel da Meta (eventos do navegador).

- `index.html`: a página
- `data.json`: totais diários (horário de Brasília), atualizados todo dia
- `merge.py`: junta uma resposta nova do Pixel ao `data.json`
